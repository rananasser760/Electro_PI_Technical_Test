# Account Security

If a customer suspects unauthorized access to their account, such as
orders they did not place or a changed delivery address they don't
recognize, they should immediately change their password from the
Account Settings screen and contact support to flag the account for
review. Support can freeze an account temporarily while an investigation
is underway, which blocks new orders from being placed but preserves
order history.

Two-factor authentication (2FA) can be enabled from Account Settings and
is strongly recommended for accounts with a saved payment method. Once
enabled, logging in from a new device requires a one-time code sent by
SMS or generated by an authenticator app, in addition to the password.

Passwords can be reset at any time from the login screen using the
"Forgot password" link, which sends a reset link to the email address on
file. Reset links expire after 30 minutes for security reasons. Customers
should never share this reset link or any verification code with anyone,
including someone claiming to be a support agent — support will never ask
for a password or a one-time code over phone or chat.

Any charges the customer doesn't recognize should be reported within 60
days so they can be investigated and, if confirmed fraudulent, refunded.
